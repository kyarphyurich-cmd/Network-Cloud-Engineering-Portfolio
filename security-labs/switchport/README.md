# 스위치 포트 보안 실습

이 저장소는 Cisco 스위치 포트 보안 기능을 다루는 실습을 포함합니다.  
Layer 2 네트워크 환경을 보호하기 위한 실무 역량을 기르는 것이 목표입니다.

## 완료한 실습

- **포트 보안(Port Security)**: 스위치 포트 보안 명령어 설정 및 동작 검증

## 예정된 실습

- **DHCP 스누핑(DHCP Snooping)**
- **동적 ARP 검사(Dynamic ARP Inspection, DAI)**
- **MAC 주소 스푸핑 방지(MAC Spoofing Prevention)**

## 실습 활용 방법

각 실습에는 다음 내용이 포함됩니다.

- 단계별 설정 명령어
- 검증 명령어 실행 결과
- 핵심 개념 정리

저장소를 클론한 후 각 실습을 따라 하며 네트워크 보안의 기초를 다질 수 있습니다.
