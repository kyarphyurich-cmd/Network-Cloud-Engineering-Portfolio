# 스위칭 실습 포트폴리오

이 폴더에는 기업 네트워크 환경을 모델로 한 **스위칭 실습**을 정리했습니다. 실제 네트워크에서 사용되는 Layer 2 및 Layer 3 스위칭 개념을 이해하고 적용하는 것이 목표입니다.

각 실습은 단순한 명령어 입력을 넘어 **설계 의도, 실제 동작, 문제 해결 과정**에 초점을 맞춥니다. 스위칭 기술을 설계하고 구성한 후, 동작을 검증하고 장애에 대응하는 과정을 기록합니다.

---

## 🎯 실습 목표

- 실습을 통해 스위칭 기초 개념 강화
- 토폴로지의 동작과 장애 복구 과정 확인
- Layer 2와 Layer 3 간 라우팅 및 스위칭의 상호작용 이해
- 네트워크 설계 및 검증 역량 향상
- CCNA 및 CCNP 학습에 필요한 기초 역량 강화

---

## ✅ 완료한 실습

### 🌀 STP — 스패닝 트리 프로토콜

STP가 Layer 2 루프를 방지하고, 링크 장애 발생 시 대체 경로로 전환하는 과정을 확인합니다.

**주요 내용**

- 루트 브리지 선출
- 포트 상태: Forwarding 및 Blocking
- 경로 비용과 우선순위 조정
- 네트워크 수렴 및 이중화 동작

---

### 🌐 VLAN 및 VLAN 간 라우팅 — Router-on-a-Stick

여러 VLAN으로 네트워크를 분리하고, 라우터의 서브인터페이스를 사용하여 VLAN 간 라우팅을 구현합니다.

**주요 내용**

- VLAN 생성 및 포트 할당
- 트렁크 포트와 액세스 포트의 차이
- 802.1Q 캡슐화
- 서브인터페이스 설계 및 기본 게이트웨이의 역할

---

## 🧭 실습 설계 원칙

- **설계 의도 명확화:** 각 구성의 목적과 선택 이유 설명
- **문제 해결 과정 포함:** 장애 상황 테스트 및 복구 결과 검증
- **기업 환경 고려:** 실제 네트워크의 확장성과 운영 상황을 고려한 토폴로지 설계
- **문서화:** 각 실습 폴더의 `README.md`에 목표와 검증 방법 기록

- Cisco Packet Tracer

- 통신 테스트용 가상 호스트
- Wireshark — 필요한 실습에서 사용

실습의 복잡도와 시뮬레이션 요구 사항에 따라 도구를 선택합니다.
